# 核心约束模板

以下约束适用于所有换装和舞蹈视频生成。使用时将 `{人物描述}`、`{场景描述}`、`{服装列表}` 替换为从参考图提取的实际内容。

## 人物一致性

中央人物是唯一持续活动的真人舞者。严格保持参考图中的同一位人物。{人物描述}。不得换脸，不得改变眼睛颜色、五官比例、发型、年龄、肤色和身体比例。

**默认人物描述（当参考图为年轻中国女性时使用，否则替换）：**
始终保持同一张纤细鹅蛋脸、柔和下颌线、琥珀棕色杏仁大眼、平行双眼皮、微扬眼尾、纤细自然眉、顺直鼻梁、小巧鼻尖、饱满浅粉色水光唇、冷调白皙肤色、中分黑色长直发、两侧细碎发丝和钻石耳坠。

## 镜头与场景

固定正面全身镜头，中央人物完整露出头顶、双手和双脚。摄影机、焦距、人物大小和位置全程稳定。背景严格继承参考图中的场景：{场景描述}。背景不变化，不出现其他人物。

**默认场景描述：**
现代奢华顶层名媛宴会厅：香槟色石材、浅色大理石地面、水晶吊灯光斑和窗外城市夜景。

## 服装表现

服装严格继承参考图：{服装列表}。

保持立体上身剪裁、清晰方领或露肩线条、弧形拼接线和收腰比例，通过服装结构呈现自然饱满、优雅立体的上身轮廓。衣服合体、稳定覆盖。缎面、丝绒、粗花呢、珍珠和水晶具有真实材质，换装后不得改变原有版型。

**默认五套服装（换装模式）：**
1. 香槟象牙白方领缎面不对称短裙
2. 酒红色丝绒方领修身短裙
3. 宝石蓝露肩修身中裙
4. 黑色短外套、方领修身上衣和高腰短裤裙
5. 玫瑰粉方领粗花呢修身短裙

## 背景音乐

同步生成原创网红名媛派对卡点音乐，124 BPM，现代 fashion house、nu-disco 和轻奢电子舞曲融合，无完整歌词。使用弹性 sub bass、干净 kick、清脆 clap、finger snap、明亮钢琴和弦、弦乐断奏与水晶闪光音。

换装模式下，在 1.25 秒、2.95 秒、4.40 秒、6.55 秒设置四个明确强重拍，6.55 秒为最强 impact。四次动作峰值、贴纸重合和服装切换必须精准对齐重拍。贴纸飞入加入短促高级 whoosh，换装加入干净 impact，不得盖过背景音乐。8.00 秒干净收尾。

舞蹈模式下，根据舞种风格调整 BPM 和重拍位置，15 秒干净收尾。

## 通用禁止项

禁止换人、增加人物、改变背景、突然变装、脸部漂移、身体扭曲、手脚畸形、额外肢体、衣服闪烁、画面抖动、瞬间位移、无规律乱跳、危险动作、频繁切镜、慢动作、字幕和水印。
