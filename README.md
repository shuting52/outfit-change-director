# 一键换装卡点导演 (Outfit Change Director)

基于参考图片，一句话生成超写实网红名媛舞蹈卡点换装视频。

## 功能特性

- **12 种换装过渡方式**（M1–M12）：贴纸飞入、袖摆遮镜、旋身接力、丝带缠绕、团扇遮挡、花瓣扩散、镜面同步、翻页翻转、分身融合、手势卡点、配饰触发、刺绣蔓延
- **14 种舞种卡点风格**：俏皮、迷人、柔美、万能、性感、性感2、甜酷、欧美、拉丁、韩系、串烧、巴西、Ama、俏皮2
- **人物一致性保障**：全程保持参考图中的同一人物
- **卡点精准对齐**：换装动作与音乐重拍完全同步

## 使用方式

1. 上传一张参考图片
2. 用一句话描述想要的效果
3. 选择换装方式和舞种风格（可选）
4. 自动生成参考图 → 确认后生成视频

## 文件结构

```
outfit-change-director/
├── SKILL.md                              # 主文件：工作流程、选项菜单、关键规则
└── references/
    ├── core-constraints.md               # 人物一致性、镜头场景、服装、音乐约束
    ├── transition-methods.md             # M1–M12 换装过渡方式详细脚本
    └── dance-styles.md                   # 14 种舞种卡点风格编排脚本
```

## 安装

可通过 GitHub URL 直接导入为 Skill 使用。
